# Zomato Operational Performance Analytics

## Project Overview
Analyzed Zomato restaurant and operational data to evaluate performance trends, customer/restaurant metrics, and key operational KPIs across multiple analytical tools.

## Tools & Technologies
- *Database & Querying:* SQL
- *Spreadsheet Analysis:* Microsoft Excel
- *Data Visualization:* Power BI, Tableau
- *Presentation:* PowerPoint

## Key Highlights & Work Done
- Cleaned, structured, and queried restaurant dataset using SQL and Excel.
- Built interactive dashboards in Power BI and Tableau to track operational metrics and KPIs.
- Summarized key insights and business takeaways for presentation.

## Files Included
- sql_queries.sql – SQL queries and data analysis scripts
- zomato_analysis.xlsx – Excel data cleaning, analysis, and dashboard
- zomato_dashboard.pbix – Power BI interactive dashboard
- zomato_dashboard.twbx – Tableau packaged dashboard
- zomato_presentation.pptx – Project summary presentation
